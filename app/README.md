# Orbique FMS live demo (app.orbiquefms.com)

`index.html` is the clickable FMS sample (three made-up companies, every page, nothing saved).
It is built from `orbique-fms/v2-sample/` in the project files (`build.py`), wrapped in a full HTML page.

Served by the separate Vercel project `orbique-fms-demo`, whose Root Directory is `app/`.
To update the demo, replace `app/index.html` and push.
